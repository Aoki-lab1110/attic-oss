# ATTIC – Open source materials

ATTIC (iOS) includes MobileVLCKit, licensed under the GNU LGPL 2.1.
Each release here contains, for the matching ATTIC version:

- complete source archives of VLCKit, VLC and every bundled component
- ATTIC as relinkable object code, so you can relink it with a modified MobileVLCKit
- instructions (RELINK.md) and verification records

Releases are tagged `attic-<version>-<build>`; the app's "Open source licenses"
screen links to the release for the installed version.

ATTICの動画再生に使っているMobileVLCKit（LGPL 2.1）の対応ソースと、
改変したライブラリでアプリを再リンクするための資料です。
アプリのバージョンごとにReleaseを分けています（`attic-<版>-<build>`）。
